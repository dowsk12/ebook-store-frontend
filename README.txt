# Livraria Virtual - E-Commerce Frontend

Uma aplicação web moderna para simular o fluxo de navegação, autenticação e compra de uma livraria online. Desenvolvida em **JavaScript Vanilla (ES6+)**, **HTML5** e **CSS3**.

## 🚀 Funcionalidades Principais
* **Autenticação de Usuários (`auth.js`):** Simulação de sistema de login e controlo de sessão.
* **Catálogo Dinâmico (`store-data.js` & `main.js`):** Exibição de produtos com capas vetoriais (SVG) e manipulação dinâmica do DOM.
* **Carrinho de Compras (`cart.js`):** Gestão de estado, adição/remoção de itens e cálculo de totais.
* **Funções Utilitárias (`utils.js`):** Módulos reutilizáveis para formatação de dados e suporte técnico do frontend.

## 🛠️ Tecnologias Utilizadas
* HTML5 Semântico
* CSS3 Customizado (Design Responsivo)
* JavaScript Modular (ES6+ Vanilla)
* SVGs Vectoriais
